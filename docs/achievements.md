# Achievement Catalogue

The table below lists the achievements that are currently emitted by the server profile subsystem. The **ID** column matches the identifier sent in the `notify` server command and is also used as the lookup key for localized HUD messages.

| ID | English name | German name | Unlock condition |
| --- | --- | --- | --- |
| `achv_distance_100km` | Road Trip | Road Trip | Drive a cumulative distance of 100 km across all races. |
| `achv_distance_500km` | Long Haul | Langstrecke | Drive a cumulative distance of 500 km across all races. |
| `achv_races_10` | Rookie Driver | Rookie Driver | Finish or participate in 10 races. |
| `achv_races_50` | Endurance Racer | Ausdauerfahrer | Finish or participate in 50 races. |

The localization keys for the HUD notification strings are maintained in `achievements_strings.csv` alongside this document.
